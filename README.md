这是一个基于STM32U575RIT6芯片，使用意法半导体公司推荐的官方图形化开发流程（即STM32CubeIde->touchgfx图形库->STM32 vscode插件的智能手表项目的早期版本。目前已经可以在开发板上运行。
一、可以做的事情：
1、使用开发板内部时钟进行较为精确的计时，实现手表的基础功能（如显示时间日期等）
2、使用MPU6050传感器检测运动姿态，实现抬腕亮屏。
3、使用MAX30102传感器检测血氧和心率值。
4、使用VEML7700传感器监测环境光，配合屏幕背光实现自动调光。同样支持切换为手动调光。
5、使用RTC内部Alarm中断实现闹钟功能。
6、游玩谷歌小恐龙。
7、内置食指终端，可以在本地储存的指令列表中随机抽取一条显示。
8、使用二次元主题，主角是明日方舟的谬因。
二、未来会做的事情：
1、设计电路及外壳，组装成真实的手表。
2、使用锂电池供电，接入电池监测，并显示电池余量。
3、优化抬腕亮屏算法。
4、增加更多的指令。
三、其他：
1、本项目大部分代码来自于deepseekv4flash。
2、所有传感器的驱动代码来自于github，并由ai进行了适配化的改造。
3、屏幕驱动代码来自于华清远见。
4、使用的图片资源少部分自绘，大部分来自于网络和touchgfx图形库。
